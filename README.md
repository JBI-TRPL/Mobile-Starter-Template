## 🛠️ Cara Menjalankan Proyek di Lokal

1. **Install dependensi:**
   ```bash
   flutter pub get
   ```

2. **Jalankan analisis kode (*Static Analysis*):**
   ```bash
   flutter analyze
   ```

3. **Jalankan seluruh pengujian otomatis (*Unit & Widget Tests*):**
   ```bash
   flutter test
   ```

4. **Jalankan aplikasi ke Emulator / HP Fisik:**
   ```bash
   flutter run
   ```
